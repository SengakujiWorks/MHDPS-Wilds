MHDPS 0.1.4 — by Sengakujiworks

Download **MHDPS-Wilds-0.1.4.zip**, import it into Vortex, then activate
**MHDPS Wilds - Web DPS Meter** in Fluffy Mod Manager. REFramework is required.
Use the mod ZIP below, not the automatic Source code archives.

Start Wilds and choose the homepage or local dashboard on first launch.
No separate Python installation or startup script is needed.

Dashboard and spectator sharing: https://mhdps.sengakujiworks.com
Open the homepage, click the share icon, and send the generated link to friends.
Viewers only need a browser; keep the host game and tab open.

0.1.4 fixes packaging so Vortex/Fluffy receives one MHDPS entry. The bundled
automatic startup functionality is retained. Part durability and multiplayer
attribution remain experimental. Source and build instructions are in the repository.
