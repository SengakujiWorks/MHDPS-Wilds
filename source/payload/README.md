# MHDPS 0.1.5
by Sengakujiworks

Zeigt Schaden und DPS deiner Jagd im Browser.
Shows your hunt damage and DPS in the browser.

DE: Spiel schließen, bisherige DPS-Mods in Fluffy deaktivieren, dieses ZIP über
Vortex/Fluffy importieren und nur MHDPS aktivieren. REFramework erforderlich.
Wilds starten und dann im Browser https://mhdps.sengakujiworks.com (mit
Zuschauer-Links) oder http://localhost:8080 öffnen. Der lokale Server läuft
komplett im Spielprozess - kein zusätzliches Programm, keine separate EXE.
Werden die Ports 8080/9999 auf dem PC bereits benutzt, können sie über die
Umgebungsvariablen MHDPS_HTTP_PORT / MHDPS_WS_PORT umgeleitet werden.
EN: Close the game, disable previous DPS mods in Fluffy, import this ZIP
through Vortex/Fluffy and enable only MHDPS. Requires REFramework. Start
Wilds, then open https://mhdps.sengakujiworks.com (with spectator links) or
http://localhost:8080 in your browser. The local server runs entirely inside
the game process - no companion program, no separate EXE. If ports
8080/9999 are already in use, override them with the MHDPS_HTTP_PORT /
MHDPS_WS_PORT environment variables.

DPS = Schaden / Questzeit. Damage / quest duration.
Eigene Auswertung; Spieldatenprüfung dieser Version noch ausstehend.
Independent implementation; in-game validation of this version is pending.
